# ISOM3360-Iran-Oil-Shock

ISOM3360 Data Mining group project. We predict whether a country will enter an
**economic stress year** (next-year inflation above 10%) from its oil exposure,
macro conditions and the global oil price, then apply the model to the 2026
Iran-related oil shock to rank vulnerable countries.

Data: [Iran Oil Shock 2026: Global Economy | ML Ready (Kaggle)](https://www.kaggle.com/datasets/tejal5kunjir/iran-oil-shock-2026-global-economic-exposure)
— compiled from EIA, World Bank, UN Comtrade, Our World in Data / Energy Institute.

## Quick start

Open this folder in VS Code, then in the terminal:

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python src/build_panel.py          # creates data/processed/panel.csv
jupyter lab                        # open notebooks/
```

## Problem setup 
| Item | Decision |
|---|---|
| Unit | country-year, 150 countries x 2010-2025 (2,400 rows) |
| Target | `stress_next` = 1 if next-year inflation > 10% (`config.py`) |
| Rows with target | 2,105; stress rate 12.4% (imbalanced) |
| Split | train 2010-2021, test 2022-2024, **no random shuffle** |
| Metrics | ROC-AUC, recall, precision, F1 (accuracy is misleading at 12% positives) |
| Seed | 42 |

### Known issues to discuss

- **Persistence effect.** Current inflation predicts next-year inflation very well
  (first logistic regression: ROC-AUC 0.95). To show oil exposure actually adds
  value, compare a model *with* oil features against one with only lagged
  inflation and GDP growth.
- **Missing != zero.** Crude trade columns are 28-41% missing. Don't fill with 0.
- **Label year overlap.** Training rows from 2021 use 2022 inflation as their label,
  so the 2022 spike is partly in training. Consider training on 2010-2020 instead.
- 2026 outcomes are not observed yet; 2026 scoring is a forecast, not validated.
